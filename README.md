# Advanced Tearable UI

A single-file tearable webpage demo built with plain HTML, CSS, and Canvas 2D.

Open `index.html` in a browser. Drag any paper section to tear it loose, use the reset button to rebuild the page, and toggle gravity from the floating toolbar. Torn sections are the original DOM nodes, so inputs, sliders, checkboxes, swatches, and buttons remain interactive after they detach.
